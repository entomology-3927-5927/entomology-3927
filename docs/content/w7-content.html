Creating visualizations in R: the tools available

There are a myriad of ways to create data visualizations in R. Indeed, a bunch of built-in tools already exist within base R to create plots, and many folks use these tools exclusively to create plots for their presentations, manuscripts, and websites. And the plots from base R…do the job…but aren’t particularly aesthetic!

One of the most important qualities of good data visualizations is that, in addition to being truthful and functional, they are beautiful. This means being cognizant about basic design and color theory and chosing the plots carefully and considerately to best serve the purpose of communicating the data. Here, the Great British Baking Show addage of “Style and Substance” comes into play. It’s possible to create incredibly data-rich plots that are truthful and functional, but you also should want to look at it – and looking at it shoudl convey an emotional response in addition to an analytical response. On the flip side, it’s possible to create a plot that is stunningly beautiful, but lacks sufficient data and analytical substance. Walking that balance is what data visualization is all about.

To accomplish this, we’ll almost exclusively be using the ggplot2 package in the Tidyverse. It’s the most flexible and well-equipped library for creating just about any sort of data visualization, and is designed to work with tidy data and the various packages that produce tidy data. In addition, many, many packages create plots that are ggplot2 objects, meaning that we can take and modify them to match a particular aesthetic, add additional information, or combine them with other plots. There’s also an abundance of code and tutorials out there to create ggplot plots.

Anatomy of a plot

ggplot plots (or objects, as we’ll be referring to them) are composed of various layers that, together, work to build a plot.

library(ggplot2)

# Data + Mapping
ggplot(data = mpg, mapping = aes(x = cty, y = hwy)) +

  # Layers
  geom_point(aes(color = displ)) +
  geom_smooth(method = "lm") +

  # Scales
  scale_color_viridis_c() +

  # Facets
  facet_grid(year ~ drv) +

  # Coordinates
  coord_fixed() +

  # Theme
  theme_minimal()
Component Purpose Common functions
Data The dataset used to create the visualization. ggplot(data = ...)
Mapping Maps variables in the dataset to visual properties (aesthetics). aes()
Layers Determines how data are visually represented, including geometry, statistical transformations, and position adjustments. geom_point(), geom_line(), geom_bar(), geom_smooth(), geom_histogram()
Scales Controls how aesthetic mappings are translated into visual properties, including axis limits, breaks, labels, and colors. scale_x_*(), scale_y_*(), scale_color_*(), scale_fill_*()
Facets Splits data into multiple panels based on one or more categorical variables. facet_wrap(), facet_grid()
Coordinates Controls the coordinate system and how spatial positions are displayed. coord_cartesian(), coord_fixed(), coord_flip(), coord_polar()
Theme Controls non-data visual elements, including backgrounds, gridlines, text, axes, and legends. theme(), theme_minimal(), theme_classic(), theme_bw()
  • Mapping (aes()) tells ggplot2 what variables to visualize.
  • Layers (geom_*()) tell ggplot2 how to visualize those variables.
  • Scales (scale_*()) tell ggplot2 how to translate those variables into visual properties.
  • Themes (theme_*()) control how the overall plot looks/the aesthetic (text, lineweight, etc.)

Mapping

Mapping connects variables on our dataset to the visual properties of a plot. They’re defined using the mapping = argument in ggplot and the various layers of our plot. They quite literally map the connection between data and plot. When we map variables to our plot aesthetics, we have two options: using (1) global aesthetics or (2) layer-specific aesthetics.

  • Global aesthetics are defined inside ggplot(mapping = aes()) and are inherited by every layer in the plot.

  • Layer-specific aesthetics are defined inside an individual geom_*() and apply only to that particular layer. There are many different aesthetic mappings in ggplot, and I describe the primary ones in the table below (there are several more specific to different layers):

Aesthetic What it controls Example
x Horizontal position aes(x = temperature)
y Vertical position aes(y = abundance)
color Color of points, lines, and outlines aes(color = species)
fill Interior color of shapes and polygons aes(fill = habitat)
size Size of points and text aes(size = abundance)
shape Shape of points aes(shape = species)
alpha Transparency / opacity aes(alpha = abundance)
linetype Line style (solid, dashed, dotted) aes(linetype = treatment)
linewidth Width of lines aes(linewidth = abundance)
group Groups observations for statistical or geometric operations aes(group = site)
label Text labels displayed on the plot aes(label = species)
Tip

Anytime we’re mapping a variable to a plot element, we use the mapping = aes() argument. If we are setting a fixed element of a plot (e.g., making all points a certain color, or a certain shape/size, those settings are controlled using the same aesthetics, but set OUTSIDE the mapping = aes() argument. For example:

# Mapping species to point color
ggplot(
  data = my_data,
  mapping = aes(x = x, y = y, color = species)
) +
  geom_point()

# Setting point color "black" to color
ggplot(
  data = my_data,
  mapping = aes(x = x, y = y),
  color = "black"
) +
  geom_point()

Layers

Layers are the actual bits and bobs that together compose our plot – things like geometries (e.g., lines, points, polygons, rectangles) and the other sets of instructions about how to actually construct it (i.e., mappings, positions, statistical transformations). Typically, we define all of these various components in our within geometries, or geoms:

ggplot(data = <DATA>) + 
  <GEOM_FUNCTION>(
     mapping = aes(<MAPPINGS>),
     stat = <STAT>, 
     position = <POSITION>
  ) +
  <COORDINATE_FUNCTION> +
  <FACET_FUNCTION>

There are many, many geometries that we can utilize in ggplot to create our plots, and I recommend you take a look at your ggplot2 cheatsheets to see most of them. There are also many add-on packages that add additional, specialty geoms that you can use to build your plots. I encourage you to search for those on your own time, as their use is beyond the scope of this course.

geom_jitter() Points with added positional variation Reducing overplotting
