📑 Workshop assignment

Practicing wrangling skills from this week: OPTIONAL

For this section, you’ll import practice-skills.csv (practice-skills in Google Sheets) and practice-joins.csv (practice-joins in Google Sheets) and conduct the various practice exercises. This section is optional to do, and you don’t need to include it in your workshop report!

Joining data

  1. Join practice-joins.csv to practice-skills.csv in using left_join(). This will append site-level metadata to our observational data

Handling missing data

  1. After joining the site metadata, replace NA values in canopy_cover and distance_to_road_m with NA

Working with strings

  1. Separate the observer_info column into 3 columns named observer, time_of_day, and survey_duration.

Working with dates

  1. Convert observation_date to the a date and create new columns for month and year into the data.

Coding factors

  1. Convert habitat to a factor that is ordered alphabetically.


Putting all the wrangling skills together: REQUIRED

For this section, you’ll import pitfall-traps.csv (pitfall-traps in Google Sheets) and pitfall-traps-sites.csv (pitfall-traps-sites in Google Sheets) and proceed to clean, tidy, and wrangle the dataset so that it is ready to plot/analyze. It will leverage all of the topics we’ve discussed over the last two weeks, and it will be up to you to critically assess the data and decide what treatments it needs in order to be ready to use. Be sure to document your process along the way using comments or other means in your .qmd report. This is a great opportunity to work with your fellow classmates to bouce ideas off one another. This section is required!

There are two columns with a complex of data included, trap-details and trap-id.

# Trap details
pitfall|PR|propylene_glycol|10cm
Position Information Example values
1 Trap type pitfall
2 Habitat code PR, WD, SV, RP, MD, WT, ED
3 Preservative propylene_glycol, salt_solution
4 Trap depth 8cm, 10cm, 12cm 
# Trap ID
S01-P1-01
Position Information Example values
1 Site ID S01, S02, S03, etc.
2 Sampling period P1, P2, P3, P4
3 Trap number 01, 02, 03, 04, 05

Once you’ve cleaned up the data, you should be able to answer the following questions by either creating new variables, or conducting some data summarizations:

  1. What was the average deployment length in number of days?
  2. Is there evidence that deployment length varied by habitat type across all sampling periods?
  3. What habitat type had the greatest total abundance of arthropods?
  4. Did athropod abundance vary across sampling periods (i.e., can we get a sense of the phenology of abundance over the season)?
Tip

For this, you’ll have to get the sampling period out of the trap_id column – it’s in there as PX where x is the sampling round. See information above!

  1. Do sites with greater tree cover tend to have more spiders than sites with less tree cover?
  2. At which site was average soil temperature highest, and how did arthropod abundance at that site compare with other sites?
  3. Which individual trap had the greatest total number of arthropods captured, and what was thre management type, habitat, and sampling date of that trap?
