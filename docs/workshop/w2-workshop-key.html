Code Style

Key Style Violations for Students to Fix

* Variable Names: Replaced non-descriptive (T, x, T_2), camelCase (MeanCount, FinalData), and mixed Camel_Snake_Case (Filter_Data_fn) with clean snake_case. Overwrote the reserved logical T.

* Spacing around operators: Added spaces around assignment (<-, =) and mathematical operators (+, -, /, %>%, ==).

* Indentation and Line Breaks: Cleaned up crammed curly braces {} and functions squeezed onto single lines with semicolons ;.

* Pipes & Long Lines: Split long tidyverse pipelines and ggplot layers across multiple lines (keeping lines under 80 characters) with operators placed at the end of lines.

* Commas: Ensured a single space follows all commas (c(x, y) not c(x,y)).
library(tidyverse)

# Load raw field sampling data
field_data <- read.csv("field_sampling_data.csv")

# Filter for active observations
active_data <- field_data[field_data$count > 0, ]

mean_count <- mean(active_data$count)

# Filter site data and calculate standardized counts
filter_site_data <- function(df, species_name, site_name) {
  if (species_name %in% df$species) {
    df_sub <- df[df$species == species_name & df$site == site_name, ]
    df_sub$count_scaled <- (df_sub$count - mean_count) / sd(df_sub$count)
    return(df_sub)
  } else {
    print("Species not found in this site!")
    return(NULL)
  }
}

final_data <- filter_site_data(active_data, "Apis mellifera", "Site_A")

# Summarize species totals
site_summary <- final_data %>%
  group_by(species, site) %>%
  summarize(
    total = sum(count),
    mean_scaled = mean(count_scaled),
    sd_scaled = sd(count_scaled)
  ) %>%
  filter(total > 10)

# Plot raw vs. scaled counts
ggplot(final_data, aes(x = count, 
                       y = count_scaled, 
                       color = species)) +
  geom_point() +
  theme_bw()
