Exercise 1: Practicing ggplot basics

Data scenario: You are an ecologist studying how insect abundance and diversity vary across habitat types and through the growing season.

Data to use: Use the w7-exercise1.csv file or the exercise-1 tab in Google Sheets.

  1. Create a scatterplot showing insect abundance over time.
    1.1 Map date to x and abundance to y.
    1.2 Add points and a smoothed trendline.
    1.3 Experiment with point color, size, and transparency.

  2. Compare abundance across habitat types.
    2.1 Create a boxplot or violin plot with habitat on the x-axis and abundance on the y-axis.
    2.2 Use fill to distinguish habitat types by color.
    2.3 Try at least two different discrete color scales.

  3. Explore the relationship between temperature and insect abundance.
    3.1 Create a scatterplot mapping temperature to x and abundance to y..
    3.2 Map habitat to color or shape.
    3.3 Add a smooth trendline.
    3.4 Change the smoothing method using the method = "<name_here>" argument. Select a method that best matches the data visually.

  4. Customize one of your plots.
    4.1 Add a title, subtitle, axis labels, and caption.
    4.2 Adjust axis breaks and labels.
    4.3 Apply a built-in theme or create a custom theme.


Exercise 2: Adding complexity – facets, themes, and customization

Data scenario: You are investigating how microclimates differ across five habitat types throughout the day. You have temperature measurements from multiple sensors in each habitat.

Data to use: Use the w7-exercise2.csv file or the exercise-2 tab in Google Sheets.

Tasks

  1. Visualize daily temperature patterns.
    1.1 Plot temperature over time using geom_point() and geom_smooth().
    1.2 Map habitat type to color.
    1.3 Customize the color scale using scale_color_brewer() or scale_color_viridis_d().

  2. Compare habitat types.
    2.1 Create a plot showing temperature distributions across habitats (think density plot, boxplot, or violin plot).
    2.2 Experiment with fill rather than color.
    2.3 Try scale_fill_manual() and scale_fill_viridis_d().

  3. Splitting the plot by faceting.
    3.1 Create a faceted plot using facet_wrap(~ habitat_type).
    3.2 Compare the faceted plot to the original plot with all habitats overlaid.
    3.3 Experiment with scales = "fixed" and scales = "free_y".

  4. Investigate temperature patterns (this may involve creating data summaries).
    4.1 Identify which habitat has the greatest daily temperature variation.
    4.2 Identify which habitat has the highest average temperature.
    4.3 Create a plot that shows both the temperature variation and highest average temperature.
    4.4 Is there any evidence that any of the 3 replicate sensors is faulty in any of the habitat types?

  5. Customize your final visualization to make it “publication quality”.
    5.1 Adjust the number of facet columns.
    5.2 Modify axis breaks and labels.
    5.3 Apply a theme (could be from ggplot or any other package).
