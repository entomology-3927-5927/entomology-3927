Topical exercises 🧑🏻‍💻

Vectors

Exercise 1: Species names and survey counts (Vector Types)

Create a character vector named species containing "Apis mellifera", "Bombus impatiens", and "Osmia lignaria". Combine it with the numeric count vector individual_counts into a single vector named survey_data, then print the class of survey_data.


Exercise 2: Biomass calculations and standardized traps (Vector arithmetic & recycling)

Convert insect dry weight values in milligrams (dry_weight_mg) to grams by dividing by 1000. Then subtract a 2-element trap-tare weight vector c(0.005, 0.008) to calculate the net insect mass in net_mass_g.


Exercise 3: Filtering quadrat sample data (Logical Subsetting)

Extract values from stem_density (stems per \(m^2\)) that represent dense plots (> 200 stems) AND are even numbers (%% 2 == 0). Store the resulting values in dense_even_plots.


Exercise 4: Imputing missing field data (NA handling)

A field logger missed soil moisture readings due to a sensor malfunction. Calculate the mean of non-NA moisture values in soil_moisture (using na.rm = TRUE) and store it as mean_moisture. Then replace all missing NA values in soil_moisture with mean_moisture. This practice is called imputing.


Exercise 5: Indexing named biodiversity indices (Vector subsetting)

You have Shannon diversity index values for insect communities at 7 sampling sites. Extract the values for "Site_B" and "Site_D" by name into control_sites. Then remove the disturbance treatment sites (positions 6 and 7) using negative indexing into disturbed_sites.



Lists

Exercise 1: Extracting elements from nesting sample lists

A field survey stores site metadata, species observations, and environmental variables in a single list. Extract the temperatures vector by name into temp_vals, then extract the third species name ("Ceratina dupla") using double bracket indexing into third_species.


Exercise 2: Applying functions across list elements

You have a list containing insect trap count vectors from three sampling locations. Use lapply() to calculate the total abundance (sum()) for each site, then use unlist() to convert the result into a clean numeric vector named site_totals.


Excrcise 3: Dynamic list modification

Create a list named pollinator_obs with two named vectors: bees = c(45, 32) and flies = c(12, 19). Then dynamically add a new element named butterflies containing c(8, 14), and update the bees element by adding 10 additional counts to each site. This also touches on vectorization which we worked on above!



Tibbles

Exercise 1: Tibble creation and sequential column referencing

Create a tibble named tree_survey containing 5 trees with species names in column species, dbh (diameter at breast height in cm) in column dbh_cm with values c(12.4, 28.1, 8.5, 42.0, 19.3), and calculate basal_area_m2 directly inside the tibble() call using the formula (pi * (dbh_cm / 2)^2) / 10000.


Exercise 2: Base Data Frame vs. Tibble Column Subsetting (drop = FALSE)

Subset column “parasite_load” from both the base data frame df_bees and the tibble tbl_bees using bracket notation [, "parasite_load"]. Print the class of each result to observe how base data frames silently simplify output to a 1D vector while tibbles preserve tabular structure.


Exercise 3: Partial Matching Prevention in Tibbles

In field data, column name typos can cause silent logical errors. Try accessing the “treatment” column of df_plots and tbl_plots using the shorthand $treat. Observe the difference in behavior.


Exercise 4: Extracting Rows, Columns, and Ranges

Given a data frame of water quality observations water_quality:

1. Extract the first 3 rows across all columns into `top_samples`.

2. Extract cell value at row 4, column "dissolved_oxygen" into `specific_do`.

3. Extract rows 2 through 5 for columns "site_id" and "pH" into `pH_sub`.


Exercise 5: Converting and Inspecting Large Biological Datasets

Convert the large insect sweep net data frame df_sweeps (100 rows) into a tibble named tbl_sweeps. Compare the console output of printing df_sweeps vs tbl_sweeps.



Code style

Excercise 1: Restyle the code below

Using the topics that we discussed earlier (and the resources in the content for Week 2), restyle the code included below to maximize readability. Some of the code elements contain stuff we haven’t talked about yet (like function and ggplot call styling). That’s ok! This is what the R style guide and Google are for. Work on this by yourself for a few minutes, and then chat with your neighbors/small groups to see if folks varied in their approach, or caught anything that you may have missed. We’ll discuss as a group briefly after that.
